### РЕКОМЕНДАЦИИ 💡

**рекомендации:**

1. В ``<Layout/>`` необходимо использовать как косвенного родителя, в этом его смысл:

`export const AppLayout = ({ children }) => { return (`<div>`{children}`</div>`); }`

2. Когда разрастется проект, `export default ...` будет неудобно использовать, лучше так: `export const ComponentName = () => { return (`<div>``</div>`); }`.

При таком подходе, как минимум, легче искать компоненты.

3. Если хочешь использовать пропсы в SVG, то логично будет передавать переменные в свойство `fill`.

4. Было бы здорово, если в проекте применялся контекст переключения темы. Обычно добавляют атрибут data-theme="light|dark" к тегу html, а в глобальном CSS, определяющем CSS-переменные, задают группу переменных для :root (светлая тема) и для :root[data-theme="dark"] (темная тема).

Когда будешь реализовывать контекст, код в `AppLayout`:

```js
  useEffect(() => {

    if (theme === 'dark') {

      document.documentElement.classList.add('dark');

    } else {

      document.documentElement.classList.remove('dark');

    }

  }, [theme]);
```

будет неактуален.

5. Нет компонента `App`. Странно, когда есть `AppLayout`, а `App` нет; в `App` обычно располагают роутинг. В целом, из моей практики, подход следующий:

в `main.jsx`:

```js
createRoot(document.getElementById("root")).render(<App />);
```

в `app.jsx`:

```js
export const App = () => {

  return (

    <div>

      <AppLayout> Другие компоненты </AppLayout>

    </div>

  );

};
```

в `appLayout.jsx`:

```js
export const AppLayout = ({ children }) => { return (<div>{children}</div>); }
```

### РЕКОМЕНДАЦИИ 💡

- комментарии в CSS переменных можно опустить. Имена переменных сами документируют себя. В дальнейшем они будут переиспользоваться и определяться в другие блоки.
- логотип-ссылка не имеет доступного имени содержит только SVG:

```javascript
<a href="#" className={styles.main}>
  <Icon name='Logo'/>
</a>
```

Для скринридера такая ссылка может быть без понятного названия. Нужно добавить aria-label, например: `<a href="/" className={styles.main} aria-label="Taskana, на главную">`

- иконки/иллюстрации декоративные, не у всех заданы aria-hidden="true"
- внешняя ссылка открывается в новой вкладке без rel. В footer есть target="_blank", но нет rel="noreferrer" или rel="noopener noreferrer" Это скорее безопасность, но для корректной ссылочной практики стоит добавить. (ссылка [https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/rel/noopener)](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Attributes/rel/noopener))
- хорошей практикой считается всегда явно указывать type для кнопок. Это может спасти от непредвиденных ошибок
